# ArMyo_Pyomyo

Este repositorio es una versión extendida y mejorada de la librería original [Pyomyo](https://github.com/PerlinWarp/pyomyo), diseñada para facilitar el uso avanzado del brazalete Myo con Python.

## 🚀 ¿Qué incluye esta versión modificada?

Esta modificación va mucho más allá de un simple fork. Se han introducido mejoras significativas que permiten un mayor control, estabilidad y capacidad de procesamiento de datos, incluyendo:

- 🔧 **Compatibilidad extendida con versiones recientes de firmware del Myo**, lo que garantiza un funcionamiento estable sin importar la versión instalada.
- 🧠 **Reestructuración del procesamiento de señales EMG e IMU**, habilitando análisis más robustos y útiles para aplicaciones personalizadas de control o aprendizaje automático.
- ⚙️ **Nuevas funciones** que permiten un manejo más complejo y flexible de los datos del sensor, incluyendo modos de activación continua, segmentación de datos y condiciones específicas de activación.
- 🔄 **Código reorganizado** para mayor claridad y facilidad de uso, con un enfoque modular para extender funcionalidades.
- 🧪 **Mejor soporte para experimentación y prototipado**, ideal para proyectos académicos o desarrollos con sensores biomédicos.
